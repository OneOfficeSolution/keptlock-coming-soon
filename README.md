# Keptlock coming-soon page

Static placeholder served by GitHub Pages at https://keptlock.com until the Keptlock app
(OneOfficeSolution/keptlock, private) goes live on Laravel Cloud. keptlock.app and
keptlock.us.com forward here from Porkbun; keptlock.dev is the staging app and shows its own
landing page.

Edit `index.html` and push to `main`; Pages redeploys in about a minute. `404.html` is a copy
so unknown paths show the same page. DNS and hosting details live in the keptlock repo,
`docs/reference/operations.md`.
